# Ларсен и Керес: колонки, строки ходов и границы комментариев

## Результат

- **Ларсен — Спасский, 1970: 19 → 34 правильных полухода из 34.** Главная линия и результат полностью совпадают с заранее проверенным образцом.
- **Керес — Винтер, 1935: 13 → 30 правильных полуходов из 37.** Сохранена линия до 15...hxg6. Перед 16-м ходом белых конвертер останавливается: исходное «Фh5:h8» ещё читается ненадёжно. PGN помечен `ExtractionStatus=incomplete`, `MissingMove=16.`, `Result=*`; результат книги хранится отдельно в `SourceResult`.

Эти результаты относятся к двум контрольным партиям, а не ко всем книгам Ларсена и Кереса. Комментарии сохраняются текстом при ходах, но их орфографическая точность и полная привязка не проверены эталоном.

## Исправления

1. Обратный скачок номеров в отдельных строках длинной нотации теперь вызывает проверку геометрии страницы. Текст не сортируется по номерам. На странице 30 книги Спасского разделитель сдвигается с 173 до 170 пунктов, освобождая слово у границы колонок: левая колонка читается целиком, затем правая. Принимается только геометрическое повторное чтение с улучшением структуры и сохранением заголовков.
2. Повреждённая строка чёрных с одной фигурной записью повторно читается из исходного изображения при 300 и 400 dpi. Английская модель читает латинские координаты; тип фигуры сохраняется из первичного текста. Для замены должны совпасть оба чтения номера, многоточия, координат и знаков. От исходной записи может отличаться только буква поля отправления; ранг, конечное поле и аннотация должны согласоваться. Это два чтения одного скана, не независимые источники и не гарантия правильности.
3. Склейка перенесённого слова «продол- / жать 8...» больше не превращает оставшийся номер из комментария в самостоятельную строку партии.
4. Разорванное взятие с повреждённым рангом, например «со: d4», сохраняется одним словом с явно напечатанным конечным полем. Раньше отдельный фрагмент «со:» мог приводить к неверной коррекции.
5. Фраза о сдаче внутри комментария не завершает текущую партию, если до следующей границы партии следует её ожидаемая строка ходов. У Кереса это рассказ о другой партии по переписке перед продолжением на 12-м ходу.

Профили символов и пороги сходства не менялись. Эталонные PGN не участвуют в конвертации и используются только для сравнения результатов. Уточнения читают исходные страницы; основной OCR-кэш остаётся неизменным. Отчёт сохраняет координаты исправленной строки, оба чтения и причину изменения.

## Воспроизводимость

`results.json` содержит сравнение с предыдущим этапом; `runs/` и `part0/`, `part1/`, `part2/` — PGN, отчёты и сохранённые входы парсера. `tested-source.json` фиксирует контрольные суммы исходников. `baseline-application.zip` содержит предыдущую доставленную версию, `this-step.patch` — изменения только этого этапа.

Следующий нерешённый участок Кереса — строка 16-го хода; её нельзя заменять ходом из эталона. Полнота других неполных контрольных партий и точность комментариев остаются отдельными задачами. Публикация на GitHub в этом этапе не выполнялась.
